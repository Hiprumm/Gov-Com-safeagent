## 1. 设计理念

### 1.1 核心定位
面向政企场景的安全运营平台，使用者包括安全运维人员、合规审计员、技术管理者。界面需传达**权威感、可信赖感、技术深度**。

### 1.2 设计方向
**「政务深蓝 × 网络安全」** —— 采用深色基调+冷色系强调色，融合政务系统的严肃性与网络安全平台的科技感。避免轻量化的白底蓝字通用风格，转向沉浸式深色仪表盘体验。

### 1.3 与旧版差异
| 维度 | 旧版 v1 | 新版 v2 |
|------|---------|---------|
| 基调 | 白底 + 蓝色强调 | **深蓝底 (#0B1120) + 青色强调 (#06B6D4)** |
| 字体 | 系统默认 | **JetBrains Mono (代码) + Noto Sans SC (正文)** |
| 布局 | 平铺Tab卡片 | **侧边导航栏 + 主内容区** |
| 动效 | 无 | **渐入动画 + 微交互** |
| 空间 | 紧凑 | **呼吸感 (gap-6/p-6)** |

### 7.3 路由配置与 404 兜底（2026-08-23 修复）

**路由清单**（[router/index.ts](file:///x:/ZuoYe/揭榜挂帅26/Gov-Com-safeagent/frontend/src/router/index.ts)）：

| 路径 | 页面 | 加载方式 |
|------|------|---------|
| `/` | HomePage（主控制台，含 4 大 Tab） | 懒加载 |
| `/evaluation` | EvaluationPage（评测报告） | 懒加载 |
| `/:pathMatch(.*)*` | 重定向 → `/` | 兜底 |

**修复的问题**：`/about` 空白页

- **根因**：Vite 脚手架残留的 `/about` 路由使用内联 template 组件对象（`component: { template: '<div>...' }`）。本项目 Vue 为 runtime-only 构建（不含模板编译器），内联 template 无法编译，页面渲染为空白；且全工程无任何入口链接指向 `/about`，属于死路由。
- **修复逻辑**：
  1. 删除 `/about` 死路由（无入口引用，直接移除）
  2. 新增 catch-all 兜底路由 `/:pathMatch(.*)*` 重定向首页——任意未知路径（含历史书签、演示时输错的 URL）不再出现空白页
- **验证结果**（浏览器 E2E）：
  - `/about` → 地址栏最终 URL 为 `http://localhost:5173/`，正常渲染首页内容 — PASS
  - 首页「工具管控」Tab 复查（5 工具卡片正常渲染，确认路由改动无副作用）— PASS
- **通用教训**：runtime-only Vue（`vue/dist/vue.runtime.esm-bundler.js`）下，内联 template 组件静默渲染为空、无任何控制台报错；脚手架残留路由应在工程初始化时清理。

### 9.4 路由与构建规范（2026-08-23 制定）

**路由定义规范**（[router/index.ts](file:///x:/ZuoYe/揭榜挂帅26/Gov-Com-safeagent/frontend/src/router/index.ts)）：

1. 路由数组**必须显式标注 `RouteRecordRaw[]` 类型**，禁止裸数组推断：

```ts
import type { RouteRecordRaw } from 'vue-router'

const routes: RouteRecordRaw[] = [
  { path: '/', name: 'home', component: () => import('@/pages/HomePage.vue') },
  // 兜底：未知路径重定向首页，避免白屏
  { path: '/:pathMatch(.*)*', redirect: '/' },
]
```

> 原因：redirect-only 兜底路由（无 component/name）与常规 component 路由混在裸数组时，TS 联合类型推断失败（TS2322），`npm run build` 的 vue-tsc 检查会报错。dev 模式（`npm run dev`）**不做类型检查**，此错误在运行时完全无感知——必须靠显式类型 + 构建检查兜住。

2. 新增路由时同步检查：导航引用（`<router-link>` / `router.push`）指向存在路由；被删路由确认无入口引用；`/:pathMatch(.*)*` 兜底必须保留且置于数组末位。
3. 禁止内联 template 组件对象（`component: { template: '...' }`）——本项目为 runtime-only Vue 构建，无模板编译器，静默渲染空白且无控制台报错。

**构建验证规范**（前端改动合入/交付前执行）：

| 步骤 | 命令 | 验证点 |
|------|------|--------|
| 1. 类型+生产构建 | `npm run build` | vue-tsc 类型检查零错误 + vite 构建成功（当前产物：7 chunks） |
| 2. 运行时验证 | 浏览器走查改动页面 | dev server 不做类型检查，类型错误只能靠步骤 1 兜住；反之白屏/渲染错误只能靠本步骤发现 |

> 双通道缺一不可：runtime 验证发现不了类型错误，类型检查发现不了渲染错误（典型案例：/about 内联 template 空白页——类型检查通过、运行时白屏；RouteRecordRaw 缺注解——运行时正常、构建报错）。
